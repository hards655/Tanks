# Android

Откройте опубликованный HTTPS-адрес игры в Chrome и поверните телефон горизонтально. Можно добавить страницу на главный экран. Сначала загрузите игру с сетью; service worker сохраняет самодостаточный HTML для повторного открытия.

Для запуска из файлов распакуйте ZIP и откройте PLAY-ANDROID.html именно в браузере с WebGL. Если файловый менеджер показывает пустой экран, используйте веб-адрес игры: поддержка локальных HTML зависит от устройства.

Параметры → размер кнопок, прозрачность, чувствительность, мёртвая зона, инверсия осей, расположение. При нехватке места размер кнопок автоматически ограничивается. Кнопки не разрешено перетаскивать друг на друга.

APK не входит в сборку. Готовый dist/index.html может быть встроен в Android WebView или оболочку Capacitor с включёнными JavaScript, DOM storage и аппаратным ускорением; потребуется Android SDK и отдельная проверка жизненного цикла/звука/полноэкранного режима. Нативная оболочка не тестировалась.
