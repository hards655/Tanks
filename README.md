# STEEL THUNDER: FIELDWORKS 4.0

3D-танковый экшен для Android Chrome и ПК. Проект использует локальный Three.js; одиночная игра работает без CDN. Мультиплеер загружает PeerJS с jsDelivr и использует внешний сервер сигнализации; требуется интернет. Покупок за реальные деньги нет.

**Скачать проект:** https://github.com/hards655/Tanks/archive/refs/heads/main.zip

## Запуск

Распакуйте архив и откройте `PLAY-ANDROID.html` в браузере с WebGL. Это самостоятельный файл со встроенными движком, кодом и интерфейсом. На Android файловый менеджер иногда открывает HTML в просмотрщике без WebGL; в таком случае используйте размещённый `index.html` через HTTPS. Сохранения привязаны к адресу и браузеру.

Локальный сервер на ПК: `python3 -m http.server 8080`, адрес `http://localhost:8080`. Телефон в той же сети может использовать LAN-адрес компьютера и порт 8080. Для установки веб-приложения нужен HTTPS/localhost. APK не собран.

## Карты и графика

Сохранены и доработаны все восемь театров: деревня и лесная долина; песчаные руины; снежная крепость; неоновый город; разрушенный мегаполис; вулкан; лунный комплекс с космопортом; затопленный порт.

- Деревья собраны из колец ствола, ветвей, ответвлений и отдельных листьев. Крон из готовых шаров или конусов нет. Три вида, по три геометрических варианта, экземпляры повторно используют геометрию.
- Шейдер ветра деформирует верхнюю часть дерева, сохраняя основание. PBR-материалы используют normal maps и карты шероховатости. Вода и лава имеют отдельные анимированные GLSL-шейдеры.
- Шейдер грунта меняет цвет в мировых координатах; устранена зависимость от необъявленного `vUv` в высоком качестве. Дороги следуют высоте физического рельефа, зона появления на снежной карте освобождена от здания.
- Нормализованы UV брони; значения цвета ограничены диапазоном байта, чтобы светлые царапины не превращались в чёрные артефакты.
- Мягкие тени, туман и ACES. Ограничение текстур грунта: до 2048 на ПК, до 1024 на мобильных устройствах. Две InstancedMesh на 88 звеньев гусениц вместо 88 отдельных движущихся объектов на танк. Обновление анимации вдали ограничено; графические настройки учитываются адаптивным разрешением.

Это WebGL-проект, не Unreal Engine и не AAA-производство. Наличие шейдеров само по себе не гарантирует уровень изображения топовых коммерческих игр. FPS и качество на конкретных Android требуют проверки.

## Арсенал

- 5 танков, модули брони/двигателя/орудия, видимые оптика, гранатомёты, экраны и ящики оснащения.
- **4 орудия**: штатное, длинноствольное, скорострельное, штурмовая гаубица. Отличаются уроном, перезарядкой, пробитием, скоростью снаряда и длиной ствола. Каждое платное орудие имеет недостатки.
- **5 снарядов**: AP, APCR, HE, HEAT, HESH. AP бесплатен в обслуживании; специальные боеприпасы имеют разную стоимость.
- **13 единиц оборудования**, до 3 одновременно: стабилизатор, досылатель, охлаждение КП, оптика, подбой, защищённая боеукладка, усиленные гусеницы, ствол, затвор, приводы, полевой инструмент, дымовые гранатомёты, укладки.
- **5 расходников**, до 2 одновременно: ремкомплект, боекомплект, топливо, усиленный заряд, паёк. Списываются только при фактическом наличии на складе.
- **14 окрасок** с заводской включительно, постоянная покупка за кредиты; не дают боевого преимущества.
- Крупнокалиберный пулемёт: лента, запас патронов, перегрев, перезарядка. Урон и награда за добивающее попадание учитываются без потери последней порции урона.

Режимы: одиночный бой, командный бой, волны, отдельная дуэль 1 на 1, дуэль с захватом и передачей флага. Осмотр всех карт доступен из гаража.

## Экономика

Старт: 1800 кредитов и бесплатный LYNX. Награда боя складывается из 160 за уничтожение, 700 за победу либо 220 за завершённый проигранный бой, 8,5% фактически нанесённого урона и 250 за пройденную волну. Затем вычитаются специальные снаряды, ремонт и обслуживание. Для завершённого боя действует минимум +100; компенсация показана отдельной строкой. Быстрый выход без действий раньше 30 секунд не приносит кредитов или XP. Повторная обработка результата не выплачивает награду дважды.

Ежедневный контракт: 5 уничтожений и 1 победа, +650 кредитов, однократная выдача, смена дня UTC. Оборудование и орудия приобретаются навсегда, снабжение расходуется. Данные сохраняются в localStorage; серверной защиты от ручного изменения сохранений нет.

## Управление

Android: джойстик слева, обзор свободным пальцем, правая сетка боевых кнопок. Дым включён в общую раскладку и не перекрывает огонь. Зоны от 44 CSS px, размер ограничивается экраном, редактор не разрешает накладывать кнопки. Обе оси джойстика имеют независимую инверсию. Обработчики pointerdown поддерживают одновременное движение, обзор и огонь; при потере фокуса ввод сбрасывается.

ПК: WASD; мышь; ЛКМ — орудие; ПКМ/Shift — прицел; Space — КП; F — лента; Q — снаряды; R — ремонт; G — дым; C — центр; Esc — пауза.

## Сборка и тесты

Node.js 20+:

```sh
npm ci
npm run check
npm test
npm run build
```

Редактируйте `src/shell.html`, JS-модули и `style.css`. `index.html`, `PLAY-ANDROID.html`, `dist/index.html` генерируются одним сборщиком, чтобы модульный код и автономная версия не расходились. После `npm run build` достаточно размещать содержимое dist на статическом HTTPS-хостинге.

47 успешно завершённых тестов Node, включая один интеграционный набор с 26 проверками: всего 72 проверки. Покрыты 30 сочетаний размера экрана и масштаба кнопок, все 8 карт, модели, боевые обработчики, независимые указатели, орудия, снабжение, покупки, экономика, шейдерные вставки, UV, нормали и непрерывность гусениц. Интеграционный набор использует настоящие Three.js-геометрию и игровую логику, но заменяет браузерные поверхности и WebGLRenderer тестовыми двойниками. Это не тест GPU и не измерение задержки касаний.

## Лицензии

Геометрия и процедурные текстуры/звуки созданы кодом проекта; чужие ресурсы World of Tanks/Borderlands не использованы. Three.js включён с уведомлением MIT. Сохраните уведомление при распространении.

Проверка опубликованной страницы: GitHub Pages отдаёт новую сборку, однако в проверочном облачном браузере WebGL отключён (`GL_RENDERER = Disabled`). Визуальный GPU-тест не выполнен; игра показывает понятное сообщение при отсутствии WebGL. Физический Android не тестировался.


## Исправления сетевой версии (17 ноября 2026)

- Сохранены ручные изменения из GitHub `7d87f27`, включая мультиплеер и просмотр карт.
- Автопоиск использует отдельную очередь версии протокола v2, чтобы не смешивать исправленные и старые клиенты.
- Снимки состояния передаются 20 раз/сек; старые/повторные/нечисловые пакеты отбрасываются. Состояния буферизуются до загрузки сцены. Хост пересылает отключения всем гостям.
- Сетевые карты генерируются в одном каноническом качестве независимо от настроек клиента: препятствия совпадают. Адаптивное разрешение продолжает работать. FPS теперь измеряется по реальному времени кадров, а не по ограниченному шагу физики.
- Исправлены восстановление HP удалённых танков, сведения об улучшенной броне, анимация гусениц, завершение сетевого боя и заморозка урона через паузу.
- Снаряд имеет профилированную форму, направлен вдоль скорости; попадания в землю создают вспышку, дым и звук. Исправлена пересекающаяся геометрия двускатных крыш и высота установки зданий.

Проверка: `npm run check`, `npm test`, `npm run build`. Сетевые тесты имитируют независимые браузеры и DataChannel: ручной вход, автопоиск, три игрока, отключения, задержка готовности, повторные пакеты. Это не тест реального STUN/TURN, мобильной сети или GPU. 60 FPS на Android не подтверждены.

P2P остаётся доверительной системой: попадания вычисляет стреляющий клиент, хост пересылает их; выделенного авторитетного сервера и защиты от читов нет. При уходе хоста матч заканчивается. В некоторых сетях прямое WebRTC-соединение может не установиться; свой TURN-сервер в проекте не настроен.
