# STEEL THUNDER: TANK WARFARE

3D tank battle game for Android browsers and desktop.

## Current project status

Repository initialized. The playable game files have **not yet been uploaded**.

## Planned game features

- Comic-style 3D visuals
- Heavy machine gun and garage shop
- Capture-the-flag duel (1 vs 1)
- Joystick left/right inversion option
- 20-level progression system
- Offline Android-friendly HTML build

## Uploading the current build

Use GitHub's **Add file → Upload files** and upload the extracted contents of `STEEL-THUNDER-JOYSTICK-SOURCE.zip`, preserving the `dist/` directory and its files.

To play the standalone build after upload, download `dist/index.html` (the build is designed for direct local opening, though Android WebGL compatibility depends on the browser).
