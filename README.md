# STEEL THUNDER: TANK WARFARE — Comic Combat 3.0

Мобильная 3D-игра для Android Chrome и ПК на Three.js. Оригинальная техника и окружение, рисованное освещение и контуры. Это самостоятельная веб-игра; уровень AAA и стабильные 30/60 FPS на конкретных телефонах не подтверждены.

## Запуск

Откройте `PLAY-ANDROID.html` в браузере с поддержкой WebGL. Весь движок и код встроены в файл; внешние CDN не нужны. На Android надёжнее открыть размещённый на HTTPS `index.html`: некоторые файловые менеджеры запускают HTML во встроенном просмотрщике без WebGL. Используйте горизонтальную ориентацию. Сохранения привязаны к браузеру и адресу игры.

Локальный запуск с компьютера: `python3 -m http.server 8080`, затем `http://localhost:8080`. Для телефона в той же сети используйте LAN-адрес компьютера и порт 8080. Установка PWA требует HTTPS или localhost. APK в этой поставке не собран.

## Что изменено

- Управление имеет единую расчётную раскладку с зонами нажатия от 44 CSS px. Размер ограничивается доступным экраном; редактор не допускает наложения кнопок. Старые конфликтующие пользовательские позиции заменяются безопасными.
- Действия запускаются по pointerdown без ожидания click. Раздельные pointerId для движения, обзора и огня; сброс удержания при потере фокуса. Надпись ремонта обновляется без пересоздания кнопки. Обновление HUD ограничено 12,5 раза/с.
- Независимая инверсия обеих осей джойстика; чувствительность обзора и прицела, мёртвая зона, размер/прозрачность, редактор расположения.
- Все 8 карт перестроены: деревня и мельницы, пустынные руины и насосы, снежные склады и бункеры, неоновые башни, промышленная зона, вулканические колонны, лунные модули, портовые контейнеры и краны. Центральные и обходные маршруты, прямоугольные объёмы укрытий, общий рельеф для движения и графики.
- Пять танков получили разные пропорции, скосы брони, катки, экраны, люки, оптику, фары, решётки двигателя, дымовые гранатомёты, антенны, пулемётные установки. Башня, орудие и пулемёт остаются отдельными подвижными узлами.
- Toon-освещение, пакетированные контуры, нормализованные UV, текстуры с mipmap-фильтрацией. 80 звеньев гусениц на танк рисуются двумя InstancedMesh; детали и анимация отдалённых танков упрощаются.
- В магазине 14 окрасок с заводской включительно: пятнистые, цифровые, полосатые, осколочные и тематические варианты. Примерка до покупки. Камуфляж не изменяет боевые характеристики.
- Сохранены 20 уровней, осмотр карт, одиночный/командный бой, волны, дуэль с флагом, КП-12.7 с лентой/перегревом, оборудование и расходники.
- Снаряд появляется у фактического дульного среза. Перезарядка, урон, модули и рикошеты сохранены.

## Управление

Телефон: левый джойстик — движение, свободная область экрана — обзор, правая группа — орудие/КП/прицел/снаряды/ремонт/захват/центр/смена ленты. Прицел циклически переключает три увеличения и обычный вид.

ПК: WASD, мышь, ЛКМ — орудие, ПКМ — прицел, Space — КП, F — лента, R — ремонт, Q — снаряд, C — центр, Esc — пауза.

## Разработка

Node.js 20+:

```sh
npm ci
npm run check
npm test
npm run build
```

`src/shell.html` — HTML-шаблон; `game.js` — интеграция; `controls.js` — размещение; `tanks.js` — модели; `maps.js` — карты; `visuals.js` — материалы/пакетирование; `paints.js` — окраски; `systems.js` — вооружение/экономика; `collision.js` — пересечение укрытий. `scripts/build.mjs` воспроизводимо создаёт одинаковые `index.html`, `PLAY-ANDROID.html` и `dist/index.html`. Не редактируйте сгенерированные HTML вручную.

## Проверки

`npm test`: 49 успешно завершённых тестов Node, включая один интеграционный набор с 22 проверками (70 проверок всего). Покрыты размеры от 568×320 до 1920×1080, масштабы .7/1/1.5, UV, геометрия всех карт и танков, непрерывность гусениц, покупки, экипировка, движения, ограничение скорости башни, снаряды, ремонт, мультитач на уровне обработчиков, КП, старт дуэли с флагом, кадр HUD и снайперский режим.

WebGLRenderer и браузерные поверхности в интеграционных тестах заменены заглушками тестовой среды; игровая логика и Three.js-геометрия настоящие. Браузерный preview в среде разработки недоступен. Физический Android, GPU-рендер, фактическая задержка касания, полноэкранный режим и FPS требуют проверки на устройстве. Это не гарантия отсутствия любых графических дефектов.

## Ресурсы

Модели, карты, процедурные окраски и синтезированные звуки создаются кодом проекта. Three.js поставляется локально с лицензией MIT в исходном файле. Платных API нет.
