# STEEL THUNDER — Winter Operations

Мобильная 3D-игра для Android Chrome и ПК. В сборку встроены Three.js и PeerJS; одиночный бой не требует интернета. Сетевой бой использует внешний сервер сигнализации PeerJS и WebRTC. APK не собран.

## Запуск и скачивание

- Игра: https://hards655.github.io/Tanks/
- Исходники и самостоятельный HTML: https://github.com/hards655/Tanks/archive/refs/heads/main.zip
- Наш ChatGPT Site: https://steel-thunder-tank-warfare-f9b4.ablazesandpiper32.chatgpt.site

Распакуйте ZIP, откройте `PLAY-ANDROID.html` в Chrome с WebGL либо используйте размещённую игру. Файловый просмотрщик Android может не поддерживать WebGL. Локальный сервер: `python3 -m http.server 8080`. Сохранение привязано к браузеру и адресу сайта.

## Мультиплеер

Оба игрока открывают одинаковую свежую версию и нажимают «Мультиплеер → Автопоиск». При наличии двух игроков начинается матч. Один игрок сам по себе не получит соперника: ботами сетевой матч не подменяется. Для игры с другом также доступны код комнаты и ручной запуск.

PeerJS теперь встроен в HTML — блокировка CDN больше не мешает загрузке сетевого модуля. Добавлены тайм-ауты подключения, освобождение зависших подключений и повторная проверка очереди одиноким хостом. Ошибка сигнализации выводится явно, поиск можно отменить и повторить.

Для друзей используйте общедоступную GitHub Pages-версию: ChatGPT Site может требовать отдельного доступа. Настройки доступа к нему автоматически не менялись. Сервер сигнализации должен быть доступен обоим участникам. Собственного TURN и выделенного игрового сервера нет: некоторые NAT/корпоративные/мобильные сети могут не соединиться. Хост пересылает данные, попадания рассчитывает стреляющий клиент; защиты от читов нет. При уходе хоста бой завершается.

## Обновление 18 ноября 2026

- Убраны неподвижные ленты и дубли звеньев, пересекавшиеся с анимированными гусеницами. При развороте ленты движутся в разные стороны. Обновление удалённых гусениц ограничено 18 раз/сек.
- Камуфляж использует смешивание трёх плоских проекций вместо растянутой UV-развёртки; масштаб рисунка задан в координатах деталей. Это процедурная окраска, не вручную нарисованные UV-атласы.
- Над танками показаны имя и HP. Укрытый противник получает контур по геометрии корпуса/башни/орудия с проверкой глубины, в пределах 140 м. Контуры не используют полноэкранный постпроцесс. Счёт живых участников и мини-карта учитывают команду самого игрока, включая P2P.
- Новый зимний ангар: кран-балка с подвесом, фермы, трубопроводы, инструментальные шкафы, подвесные гирлянды и тёплый/холодный свет. Снижена засветка брони.
- Бесплатная танковая гирлянда включена по умолчанию; кнопка «Гирлянда надета · снять» в характеристиках и переключатель в настройках. Выбор сохраняется. Лампочки объединены в InstancedMesh, без индивидуальных источников света.
- Генератор восьми карт использует разные исходные числа и палитры: три широких маршрута, поперечный проход, 24 группы укрытий, свободные точки появления и растительность вне проездов. Статическая геометрия повторно используется и объединяется. Это процедурные тактические арены, не вручную смоделированные AAA-уровни.
- Снаряды проверяют первое столкновение с танком или ориентированным укрытием. Высота укрытия учитывается: выстрел выше крыши не блокируется невидимой сферой. Сохранены профилированная форма снаряда, вспышки, дым и звук попаданий.

## Сборка и проверки

`npm ci`, `npm run check`, `npm test`, `npm run build`.

67 тестов Node, включая интеграционный набор из 30 игровых проверок. Проверяются ручные комнаты, автопоиск, три игрока, поздний вход в очередь, тайм-аут сигнализации, отмена, старые пакеты, пути/спавны всех карт, предел геометрии, проекция окраски, гусеницы, гирлянды и попадания. Сетевые тесты используют имитацию независимых браузеров и DataChannel, а игровая интеграция — реальный Three.js без GPU.

Реальные соединения через мобильный интернет, компиляция шейдеров драйвером и FPS на Android здесь не проверены. Цель — плавная работа с адаптивным разрешением; гарантии 60 FPS нет.

Сторонние лицензии: `vendor/three.js`, `vendor/peerjs-LICENSE.txt`. Модели, планировка, текстуры и звук игры процедурные.


## BATTLEFIELDS / 8 — полная замена уровней

Устаревшие боевые планировки, включая LUNA-9, заменены. Сохранены восемь названий. В `authored-levels.js` заданы отдельные координаты зданий, дороги, ориентиры и холмы каждой карты. Это явно заданные композиции, а не перестановка одинаковой сетки. `level-art.js` собирает детализированные модульные здания, кровлю, порталы, рёбра, окна, промышленное оборудование и скалы. Компоненты объединены по геометрии и материалу в InstancedMesh.

| Карта | Новая композиция |
| --- | --- |
| Зелёная долина | Посёлок вокруг мельницы, отдельные фермы, обходы между холмами |
| Пустынный рубеж | Ущелье, караван-сарай, нефтебаза и широкие обходы |
| Зимний фронт | Бункеры, батарея, ангары и лесной маршрут |
| Неоновый каньон | Башни, площадь, транзитная станция и сервисные улицы |
| Ржавый мегаполис | Литейный цех, заводские кварталы, контейнерные дворы |
| Вулканический разлом | Обсидиановые гряды, геостанция и эвакуационный маршрут |
| Лунная база | Арочные жилые модули, посадочные ангары и энергоблок |
| Затопленный порт | Склады, контейнеры, краны и сухие маршруты по причалу |

Рельеф используется и графикой, и физикой; дороги повторяют его высоту. Названия трёх зон доступны в осмотре карты. Столкновения корпуса учитывают повёрнутые прямоугольники зданий. Видимость и попадания учитывают высоту укрытий. Боты получили A* для обхода препятствий; поиск пути ограничен по частоте и использует общую сетку проходимости.

Готовность: 77 автоматических тестов, включая достижимость всех точек появления/центра на всех картах тяжёлым танком, конечность геометрии, нормали дорог, отличия планировок, ограничения статической геометрии и 30 игровых проверок. Отчёт по числу деталей и отрисовываемых групп: `level-budgets.json`. Это не измеренный FPS. В этой среде визуальный результат на GPU и Android не проверен. Разрушаемость зданий и выделенный сетевой сервер не добавлены. Старые и новые клиенты разделены по очереди автопоиска, поскольку карта и физика должны совпадать.
